# Oakridge Bangalore Rocketry Club 🚀

Welcome to the official repository of the **Oakridge Bangalore Rocketry Club**.  
This space is used to store, track, and showcase the various rockets and experiments built by our team.

---

## 🔭 About Us

The **Oakridge Rocketry Club** is a high-school rocketry team of ~10 passionate builders, designers, and experimenters.  
We work hands-on with engineering concepts across:

- **Thrust Vector Control (TVC)**
- **Avionics & Telemetry**
- **Parachute Ejection Systems**
- **Flight Software & Simulation**
- **Custom Rocket Design & Fabrication**

Our goal: learn by building, test by launching.

---

## 🧪 Current Projects

- **Parachute Ejection System**  
  Testing reliable, altitude-based recovery triggers.

- **Avionics Stack**  
  Custom flight computers, logging, sensors, and tracking.

- **TVC Rocket Program**  
  Closed-loop control with servo-driven gimbal systems.
