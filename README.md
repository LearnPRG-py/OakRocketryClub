This is the repository that we, the Oakridge Bangalore Rocketry club, use for storing and displaying content pertaining to the various rockets built.

#Information about the club
Oakridge Rocketry Club is a high school rocketry club with around 10 members working on numerous key projects. We are currently working on parachute ejection, avionics and thrust vector control.

#Contribution policy
We do *not* encourage external contributors outside of direct club members. Please contact us externally via email for any communication.
